# Contributing

Use GitHub issues to report reproducible bugs or discuss a proposed feature. Include the Python version, operating system, command, expected behavior, actual behavior, and a small synthetic input. Remove credentials and private data from logs.

For a pull request, keep changes focused, explain the behavior affected, and include the commands you ran. Update usage documentation when behavior changes. Add tests for new behavior or a reproduced defect when appropriate.

Check the repository's license and any upstream data licenses before distributing code or datasets. Training and evaluation claims should include their inputs, configuration, hardware, and limitations.
